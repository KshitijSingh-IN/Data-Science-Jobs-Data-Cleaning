# Data-Science-Jobs-Data-Cleaning
"Cleaning and analyzing Data Science job postings using Excel, SQL, and Python."
# 🚀 Data Science Jobs: End-to-End Analysis 📊

This project demonstrates a complete data analysis workflow, starting from a messy dataset and transforming it into actionable insights.

## 🛠️ Phases of the Project:
1. **Excel (Data Cleaning):** Handled missing values, formatted salaries, and extracted skills (Python/SQL) using formulas.
2. **SQL (Database Management):** Imported data into MS SQL Server and wrote complex queries to find top-paying companies.
3. **Python (Visualization):** Used Pandas and Matplotlib to create a bar chart showing the top job locations.

## 📈 Key Findings:
- Major tech hubs like **New York** and **San Francisco** dominate the job market.
- High-paying sectors like **Biotech** and **Finance** offer the most competitive salaries.
